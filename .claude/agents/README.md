# Claude Code Alt-Ajanları (The Agency — küratörlü set)

Kaynak: https://github.com/msitarzewski/agency-agents (MIT lisansı,
commit `c89557f78509868c6d4cc08e5cbc79bc8625fe1c`).

Bu klasördeki `.md` dosyaları Claude Code'un **proje alt-ajanlarıdır**;
oturum başında otomatik yüklenir ve Agent aracıyla çağrılır
(ör. "frontend-developer ajanıyla şu bileşeni yap").

294 ajanlık tam rosterdan bu projelere uygun 48 ajan seçildi:
web geliştirme (engineering), tasarım (design), SEO/AEO ve içerik
(marketing), test/erişilebilirlik/performans (testing), ürün (product),
müşteri desteği + KVKK uyumu (support), satış teklifi (sales), uygulama
güvenliği (security), reklam (paid-media) ve özel seçki: müşteri hizmeti,
emlak alım-satım, fiyat analizi, çevirmen (specialized).

Yeni ajan eklemek: kaynak repodan istediğin bölümün `.md` dosyasını bu
klasöre kopyala ve commit'le. Güncelleme: aynı dosyaları upstream'den
yeniden kopyala.
